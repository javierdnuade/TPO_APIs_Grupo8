14-03
Backend - Dashboard de estadisticas (modulo general)
Persistencia y modelo (JPA)
- Entidad Cuota: Se agrego el atributo pagada (boolean) para permitir el seguimiento del flujo de caja y estados de mora.
- CreditoRepository y CuotaRepository: Se desarrollaron consultas personalizadas con @Query (JPQL) para calculos de agregacion:
  * Suma total de capital prestado.
  * Conteo de creditos pendientes de aprobacion.
  * Suma de intereses ganados (basado en cuotas liquidadas).
  * Identificacion de mora (cuotas impagas vencidas).

Arquitectura y capa de negocio (service)
- Patron de diseno: Inversion de Dependencias mediante interfaz DashboardService e implementacion DashboardServiceImpl.
- DTO: Se creo DashboardResponseDto para encapsular las metricas y enviarlas al frontend de forma segura y desacoplada.
- Logica: Manejo de valores nulos y calculos de promedios para estabilidad ante bases de datos vacias.

Endpoints REST (controller)
- DashboardController: Endpoint GET /api/dashboard/stats.
- Respuesta: ResponseEntity con codigos HTTP adecuados y formato JSON.

Seguridad (JWT)
- SecurityConfig: Se actualizo el SecurityFilterChain para incluir la proteccion del modulo.
- Autorizacion: Solo usuarios con ROLE_ADMIN pueden acceder a los datos estadisticos.
- Validacion: Se valida la firma del token JWT mediante JwtAuthFilter antes de permitir el acceso.

Instrucciones para demo (video)
- Mostrar el DTO y las @Query en los repositorios.
- Probar en Postman acceso denegado (403) sin token de Admin.
- Probar acceso exitoso (200) enviando JWT de Administrador.
