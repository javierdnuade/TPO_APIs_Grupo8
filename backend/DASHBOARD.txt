TPO APLICACIONES INTERACTIVAS - ENTREGA 1 (BACKEND)
MÓDULO: DASHBOARD DE ESTADÍSTICAS
=========================================================

RESUMEN DE CAMBIOS Y FUNCIONALIDADES IMPLEMENTADAS:

1. PERSISTENCIA Y MODELO (JPA)
---------------------------------------------------------
- Entidad 'Cuota': Se agregó el atributo 'pagada' (boolean) para 
  permitir el seguimiento del flujo de caja y estados de mora.
- CreditoRepository & CuotaRepository: Se desarrollaron consultas 
  personalizadas con @Query (JPQL) para realizar cálculos de 
  agregación eficientes:
    * Suma total de capital prestado (Credits sum).
    * Conteo de créditos pendientes de aprobación.
    * Suma de intereses ganados (basado en cuotas liquidadas).
    * Identificación de mora (cuotas impagas vencidas).

2. ARQUITECTURA Y CAPA DE NEGOCIO (SERVICE)
---------------------------------------------------------
- Patrón de Diseño: Se aplicó Inversión de Dependencias mediante 
  interfaz (DashboardService) e implementación (DashboardServiceImpl).
- DTO (Data Transfer Object): Se creó 'DashboardResponseDto' para 
  encapsular las métricas y enviarlas al Frontend de forma segura 
  y desacoplada de las entidades del modelo.
- Lógica: Manejo de valores nulos y cálculos de promedios para 
  asegurar la estabilidad del sistema ante bases de datos vacías.

3. ENDPOINTS REST (CONTROLLER)
---------------------------------------------------------
- DashboardController: Se implementó el endpoint GET /api/dashboard/stats.
- Cumplimiento de estándares REST: Retorno de ResponseEntity con 
  códigos de estado HTTP adecuados y formato JSON.

4. SEGURIDAD (JWT)
---------------------------------------------------------
- SecurityConfig: Se actualizó el SecurityFilterChain para incluir 
  la protección del nuevo módulo.
- Autorización: Se configuró seguridad de grano fino mediante roles. 
  Solo usuarios con 'ROLE_ADMIN' pueden acceder a los datos 
  estadísticos.
- Validación: El sistema valida la firma del Token JWT mediante el 
  JwtAuthFilter antes de permitir el acceso a los datos sensibles.
